# LiDAR 航向剖面与动态剖面布局设计

## 1. 背景与目标

当前四个剖面按 map XY 固定方向提取，不能随 LiDAR 的当前航向变化。本功能将剖面改为“水平航向跟随 LiDAR、竖直方向固定 map Z”，并增加当前 GUI 会话内的剖面编辑、新增、删除和动态布局。

本设计只影响可视化剖面和剖面布局，不改变点云配准、ICP、导出矩阵或 `src/frame_register_manual.py`。

目标 worktree：`D:/w/fr`；目标分支：`feature/new-frame-features`；基线提交：`9362f69a`。

## 2. 已确认需求

### 2.1 默认剖面

默认打开 GUI 时创建四个剖面，并采用 2×2 剖面布局：

| 逻辑位置 | 名称 | 相对 LiDAR 水平 X 轴角度 | 可编辑 | 可删除 |
|---|---|---:|---|---|
| `(0,0)` | XZ | `0°` | 否（固定基准） | 否 |
| `(1,0)` | YZ | `90°` | 否（固定基准） | 否 |
| `(0,1)` | Diag +45° | `+45°` | 是 | 否 |
| `(1,1)` | Diag -45° | `-45°` | 是 | 否 |

逻辑位置使用“行、列”表示。3D 视图位于剖面网格上方并横跨全部列。

### 2.2 航向跟随规则

剖面只跟随当前 LiDAR 的 map 平面航向 yaw：

```text
heading = atan2(R_corrected[1,0], R_corrected[0,0])
```

其中 `R_corrected` 为当前 `corrected_T_map_lidar` 的旋转块。

构造水平基向量：

```text
x_heading = [cos(heading), sin(heading), 0]
y_heading = [-sin(heading), cos(heading), 0]
z_map     = [0, 0, 1]
```

剖面角度 `θ` 相对于 `x_heading` 定义：

```text
u = cos(θ) * x_heading + sin(θ) * y_heading
v = -sin(θ) * x_heading + cos(θ) * y_heading
w = z_map
```

其中：

- `u` 是剖面横向投影方向；
- `v` 是剖面厚度方向；
- `w` 是固定 map Z 高度方向。

因此 yaw 改变会使所有剖面在水平面内同步旋转；pitch/roll 不会使剖面高度方向倾斜。

剖面中心使用当前 LiDAR 原点 `C_current`。角度模式的中心为 `C_current`；平行偏移模式会在水平面内对中心进行偏移。

### 2.3 剖面编辑模式

每个可编辑剖面支持两种模式。

#### 角度模式

参数：

```text
angle_deg ∈ [-180°, 180°]
```

剖面通过 `C_current`，角度相对于当前 LiDAR 水平 X 航向定义。

#### 平行偏移模式

参数：

```text
reference ∈ {XZ, YZ}
offset_m ∈ 有限实数
```

剖面方向与参考剖面平行，仅沿其水平法向偏移。

采用右手法向约定：

- XZ 的正偏移方向为 `+y_heading`；
- YZ 的正偏移方向为 `-x_heading`。

偏移剖面仍使用 `z_map` 作为高度方向。

默认对角剖面也可切换到平行偏移模式，因此 `(0,1)` 和 `(1,1)` 可以修改位置但仍不可删除。

### 2.4 新增和删除剖面

最多新增两个剖面：

| 新增顺序 | 逻辑位置 | 默认模式 | 默认值 |
|---|---|---|---|
| 第一个 | `(0,2)` | 角度模式 | `+90°` |
| 第二个 | `(1,2)` | 角度模式 | `-90°` |

新增剖面可编辑、可删除。固定的四个默认剖面不可删除。

当前剖面数量为 4 时使用 2×2 布局；数量为 5 或 6 时使用 2×3 布局。新增、删除和参数修改只在当前 GUI 会话生效，不写入 YAML；关闭 GUI 后重新打开恢复四个默认剖面和 2×2 布局。

## 3. 推荐架构

采用“基于统一剖面描述和水平基向量的几何实现”。不采用只旋转 3D 覆盖而保留旧 2D 提取的方案，因为该方案会造成 2D 与 3D 语义不一致。

### 3.1 剖面描述

将每个剖面描述为独立的运行时对象，至少包含：

```text
profile_id
display_name
grid_row
grid_column
angle_deg
mode
reference
offset_m
deletable
```

默认剖面和新增剖面共用同一描述结构；`deletable` 仅用于区分固定剖面和会话新增剖面。

### 3.2 2D 剖面提取

提取接口改为接收中心和三个方向向量，而不是只接收 map XY 角度：

```text
extract_slice(points, center, along_axis, across_axis, height_axis,
              half_length, thickness)
```

计算：

```text
relative = points - center
along = relative · along_axis
across = relative · across_axis
height = relative · height_axis
```

保留满足半长和厚度约束的点，并返回 `(along, height)`。

这样 map 点云和调整后点云使用同一套剖面几何，且高度始终是 map Z 投影。

### 3.3 3D 剖面覆盖

3D 覆盖与 2D 剖面共享同一组 `center/u/v/z_map`。覆盖显示为垂直于水平面的薄带/矩形：

- 长边沿 `u`；
- 厚度沿 `v`；
- 高度沿 `z_map`；
- 中心跟随 `C_current` 和偏移规则。

覆盖的水平朝向和 2D 投影必须来自同一计算结果，避免出现 3D 标记方向与 2D 剖面不一致。

### 3.4 动态布局

`MainWindow` 根据当前剖面列表重建可视化网格：

```text
4 个剖面：2 列
5~6 个剖面：3 列
```

场景控件横跨当前列数；剖面控件按 `grid_row/grid_column` 放置。新增和删除只改变剖面网格及其覆盖图元，不触发重新加载点云。

### 3.5 剖面管理控件

在右侧控制栏增加剖面管理区域：

- 当前剖面列表；
- 模式下拉框：角度 / 平行偏移；
- 角度输入框，范围 `-180° ~ 180°`；
- 参考剖面下拉框：XZ / YZ；
- 偏移距离输入框，支持正负值；
- 新增按钮，最多新增两个；
- 删除按钮，仅新增剖面启用。

XZ、YZ 的位置和删除操作锁定；默认对角剖面位置可编辑但删除按钮禁用。

## 4. 错误处理与兼容性

- 角度超出 `[-180°, 180°]` 时拒绝更新并保留上一次有效值；
- 偏移距离必须为有限数值；
- 新增超过两个时按钮禁用；
- 不能删除固定剖面；
- 点云为空时保持现有空剖面提示；
- 不改变 `T_manual_map`、`T_corrected_map_lidar`、ICP、导出 YAML 和 PCD 逻辑；
- 不修改 `src/frame_register_manual.py`；
- 不将剖面会话状态写入配置文件或导出文件。

## 5. 测试策略

### 5.1 几何单元测试

覆盖：

1. yaw 为 0 时，XZ/YZ 与 map X/Y 水平方向一致；
2. yaw 改变后，XZ/YZ 只在水平面内旋转；
3. pitch/roll 改变不会改变剖面的 map Z 高度方向；
4. `+45°/-45°` 相对于当前航向正确；
5. 角度模式投影坐标和厚度筛选正确；
6. XZ/YZ 平行偏移的正负方向正确；
7. 3D 覆盖和 2D 提取使用同一方向向量。

3. 新增第二个剖面放在 `(1,2)`；
4. 5/6 个剖面使用 2×3；
5. 新增剖面可删除；
6. 默认四个剖面不可删除；
7. 新建 GUI 实例恢复 4 个默认剖面和 2×2；
